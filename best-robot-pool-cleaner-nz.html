Best Robot Pool Cleaner NZ: Which to Buy

Robot pool cleaners aren't one-size-fits-all — above-ground and in-ground pools often need different models, and the time they actually save depends on how much manual cleaning you're doing now.

Twisti guides · Updated July 2026

Above-ground vs in-ground: check compatibility first

Many robot pool cleaners are designed specifically for one pool type. In-ground pool robots are often built to climb walls and clean waterline scum in pools with steeper, more rigid sides, while above-ground models are designed for the shallower, sometimes softer-sided pools common in backyard setups. Using the wrong type can mean poor wall-climbing performance or, in some cases, the cleaner struggling to grip a liner it wasn't designed for. Always check the manufacturer's compatibility list against your specific pool type before buying, not just pool size.

Cleaning cycle time — set realistic expectations

Most robot pool cleaners run a full cleaning cycle of somewhere between one and three hours depending on pool size and the model's programmed pattern, and they're not designed to run continuously — you set it going, it cleans, then it stops or needs to be removed from the water. This is different from a robot vacuum you can run daily with minimal thought; most owners run a pool robot every few days to weekly during pool season rather than daily, which is usually sufficient to keep a pool clean between full manual services.

Cost vs manual cleaning — the real comparison

A robot pool cleaner is a genuine time-saver if you're currently manually vacuuming and brushing a pool weekly during summer — that's real hours back over a season. But it doesn't replace all pool maintenance: you'll still need to manage chemical balance, skim leaves and debris off the surface, and check the filter or filtration system regularly. Weigh the upfront cost against realistic hours saved over a pool season, not against doing zero maintenance — a robot cleaner handles the floor and walls, not the whole job.

What to check before buying

  • Pool type and size limits — confirm the model is rated for your pool's length and type, not just "suitable for most pools."
  • Cable length (for corded models) — a cable too short for your pool size is a common and frustrating mistake; measure your pool's longest dimension first.
  • Filter basket ease of cleaning — top-load, easy-access filter baskets save real hassle after every clean compared to models that need more disassembly.
  • Climbing ability — if you want waterline and wall cleaning, check the model is specifically rated for climbing, not just floor cleaning.
  • Storage and portability — some models come with a caddy for easy storage and transport out of season; worth considering if you're storing it away over winter.
Before you buy: Harvey Norman, Mitre 10 and specialist pool shops all stock robot pool cleaners in NZ, with genuine price variation between above-ground and in-ground rated models — confirm which type you need before comparing prices.
